# Host SSH and Git refresh boundary

The application owns both complete refresh policies through eight required
synchronous ports. Commands expose only a readonly lazy status observation;
existence and three fixed reports supply the remaining decisions. Construction
validates callability without host effects. Target IDs come from existing verified
lifecycle composition; these observations provide no new container authority.

Each private Docker wrapper constructs fresh native ports and application.
Native construction captures no home, path, runtime or process observations.
SSH computes host path before CLI selection and dispatch; refresh always runs,
including absent host source. Existence and warning are evaluated only after
status is not strictly zero. This retains stale credential invalidation.

Git computes its first home/config path and existence before runtime selection.
Missing config performs no command. Presence captures runtime once, then the
second home/normalized SSH root before staging. Installation shares those exact
values. Stage failure reports and returns; install failure reports. Raw native,
existence, status-getter or report throws propagate unchanged. No retry, timeout
or cleanup policy is added. Native reports preserve console.error receiver and
the original generic warning bytes, never commands or credential contents.

Canonical executable assets live in the native ssh-material module. Docker
directly reexports the same functions with original names, defaults and arities.
The Python provenance asset stays unchanged. Independent pre-extraction hashes
and generated values must match SSH default/false/true, signing and Python
outputs; comparing only two new imports is insufficient evidence.

Existing/create callbacks stay separate, receiving verified IDs and preserving
SSH-before-Git ordering. Verify core status/fault traces, fresh native capture and
exact argv/options, actual facade/lifecycle paths, emitted types, existing private
shell/UID/marker/provenance tests and both real shipped payloads. Private helpers
are not exported merely to make testing easier.

## Known ceiling

This moves one credential refresh family. Host directory preparation, Codex host
access restoration, SSH agent/auth/custom configuration and final composition
remain separate work. Source mounts, privilege boundaries, key modes and markers
gain no new policy. Portable/fenced execution does not certify real Mac/runtime
mount UID behavior. No real keys are read for architectural verification.
