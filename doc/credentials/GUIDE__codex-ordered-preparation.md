# Ordered Codex configuration preparation

The application owns directory-before-file preparation through twelve required
synchronous ports. Compose the retained probe/repair/finalize leaf twice;
complete the directory stage before constructing the file stage. The historical
public facade remains synchronous void with the same name and two arguments.

Resolve the selected config once. Each repair checks live host identity, parent
metadata and directory ownership before config metadata. The native adapter
classifies an actual lstat ENOENT as missing only when directory repair permits
absence. File repair propagates the original lstat failure without inspecting
its properties. Metadata getters and generated unsafe-file refusals are outside
that absence catch and stop preparation before mapped-UID or root ACL effects.
Unexpected nullish failures propagate unchanged.

Mapped container UID is read lazily after successful validation, reused within
one invocation, and fresh for subsequent or nested invocations. Native ports
receive the resolved host path explicitly for existing diagnostics. Keep native
result decoding in the native adapter: applications consume finite ready,
repair-required, timed-out and failed observations. Pass detailed native stage errors as opaque failures; do not inspect error codes
again once the native adapter has constructed the public failure.
Keep live runtime selection per command, fixed ACL scripts and existing lock callers.
UID lookup selects its runtime before the repair command selects its runtime.

Verify ordering, host safety refusals, directory/file absence asymmetry,
fresh/reused/nested UID state, and failure suppression at the application and
public native facade. Qualify both shipped payloads with emitted type consumers.
Use private synthetic fixtures, never real credential material.

## Known ceiling

This internal parity extraction does not prove real runtime/platform/UID mapping,
rootless/SELinux/remote behavior or filesystem races. A successful repair followed
by failed verification remains a partial native mutation and propagates without
retry or rollback. Remaining M11 operations and M12-M14 remain separate work.
