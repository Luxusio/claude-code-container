# Credential paths follow execution context

Credential resolution now follows actual host/container context regardless of test-runner variables. Existing profile/default/legacy paths and private directory preparation remain, including the distinct named-profile Claude and Codex container rules. Host fixtures select their environment explicitly; the existing application/native helpers share this policy without an added service. The [requirement](../credentials/REQ__credential-execution-context.md), [Guide](../credentials/GUIDE__host-paths.md) and [audit](../common/AUDIT__architecture-current-boundaries.md) record behavior and scoped evidence. This does not certify credential transfer, mount/UID/ACL authority, native or installed delivery, full Source/reliability/Goal acceptance or formal workflow attestation; the eight original legacy test-type diagnostics remain qualified separately.
