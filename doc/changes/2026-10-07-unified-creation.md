# Unified workspace creation application

Unified workspace creation now composes the shared addition policy with explicit
registration, naming, nested repair and root compensation ports. Its native
binding preserves existing Git/filesystem authority and helper arguments. Only
nested-repair exceptions start cleanup; validation, naming and result-assembly
failures retain their previous direct propagation.

The application preserves root-first results, nested entry identity/order,
mutable arrays and exact error/cause behavior. Result/action types now have pure
domain ownership while legacy facade imports remain valid. Core/facade/type
tests and both real shipping payloads verify that boundary and compatibility.

## Known ceiling

Outer dispatch, multi-repo creation, nested repair internals and overall removal
remain future migration work. This change does not finish M11 or the entire
architecture transition, and portable tests do not certify native Mac/Windows
VM execution.
