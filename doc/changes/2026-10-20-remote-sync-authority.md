# Bind remote synchronization to its verified session

Remote sync admission, waiting, public termination and cleanup use complete
structured inventory and captured native identifiers. Names separate project
and SSH authority; legacy, duplicate, unknown and foreign records cannot grant
mutation authority. Checked replacement and creation retain exact binding proof,
and existing project/container guards serialize admission with cleanup. Public
termination requires valid saved configuration and checked native completion.
See the [sync authority requirement](../remote/REQ__sync-authority.md).

## Known ceiling

This conversion does not certify the existing SSH `docker://…` path as a working
container transport. Live SSH, container transport, native platform/engine
acceptance and reusable remote exit/cancellation remain separate work before
the full architecture goal can close.
