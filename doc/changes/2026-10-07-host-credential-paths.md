nine explicit ports and package-path data. Public Docker exports retain their
signatures; dynamic helpers, getter order, sparse creation modes and partial
failures remain unchanged. Matching build and five configured type checks,
16 focused suites (939 tests), scoped lint and one actual dual-payload verifier

helper uses the current homedir, so the private fixture expectation now checks
its synthetic home. The named-profile override and VITEST-key distinction remain

## Known ceiling

Directory preparation does not certify credential transfer, migration, mount
authority or real native runtime behavior. Other architecture packets and the
Docker-outside-Docker real-host limitation remain separate.
