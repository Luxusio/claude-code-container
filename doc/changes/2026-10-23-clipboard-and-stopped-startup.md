# Clipboard reconnection and stopped-container startup

The X11 clipboard bridge refreshes a validated host port and token together while preserving its configured hostname and paired fallback. A provisionally admitted stopped container can be requalified through a read-only trusted-image nonce helper before guarded replacement; startup responsibility is published immediately before a native mutation, so read-only preflight refusal leaves no artificial pending startup claim. Other sessions, source files and retained data remain protected.

## Known ceiling

Missing clipboard endpoint provisioning, historical uncertain pending claims and actual macOS/Windows acceptance remain unresolved by this portable repair. The nonce helper refuses inherited destinations outside approved CCC paths. See [clipboard requirements](../common/REQ__clipboard-text-copy.md) and [stopped-container recovery](../session/REQ__stopped-container-upgrade-recovery.md).
