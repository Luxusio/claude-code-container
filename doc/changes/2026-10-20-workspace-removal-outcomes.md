# Workspace removal outcomes

Workspace removal exposes typed results and progress without console or process-exit capabilities. CLI rendering and remedies stay in the outward adapter; ownership, session, runtime and conditional cleanup guards remain in the application. Admitted container IDs are copied before native callbacks, and a completed workspace result remains available if later cleanup fails.

Portable application, CLI and private Git evidence does not establish native macOS/Windows acceptance or whole-architecture completion. Failure can follow partial native effects and does not imply rollback.
