# Direct physical attachment

Android and iOS native facades compose `createPhysicalAttachmentApplication`
through the checked `adapters/physical-attachment.mjs` producer. The application
owns complete attach admission, duplicate checks, attachment data, owner
publication, exact lease compensation and heartbeat activation. Android claims
the Wi-Fi target lease before ADB connect. The native adapter reports semantic
connect success with an opaque receipt and inventory attachability; the application
uses those facts and retains the observed state only for refusal detail. Connect
keeps the existing native status0-only success rule. Inventory must then confirm
a usable physical device. iOS requires xctrace visibility and existing network pairing
for Wi-Fi attachment. Neither path creates an emulator or powers hardware.

Detach reuses the accepted physical-stop lifecycle/cleanup peer. It claims the
exact record, stops only owned auxiliary resources and checks the same lifecycle
generation before owner removal. The accepted physical-lease transaction owns
atomic lease publication; the attachment application supplies exact-record CAS
and guarded owner restoration on commit failure. A successor is never removed.
An iOS recorder confirmed stopped remains inactive when later Appium cleanup
fails; Appium metadata and the physical lease remain available for retry.

The application returns finite missing, error, command-failure, conflict,
attached and detached outcomes. Native facades alone project target status and
render MCP responses. Discovery, inventory decoding, serial/slug/port derivation,
actual ADB arguments, clocks/nonces, ownership, file locks, process identity and
lease generation guards remain outward. The native producer constructs required
ports and fixes the connect argv; it does not forward an application ports bag.

Static contracts consume the actual factory and native producer bodies and
reject missing or asynchronous synchronous leaves. This establishes the checked
producer's finite leaf-contract ceiling, not checkJs coverage of every legacy
backend/helper body. Ordinary current core and whole native-fixture journeys
qualify business failures, compensation, successor protection and public output.
Controlled Linux fixtures do not certify real Android/iOS hardware, shipping or
final delivery. Broker attach/detach already uses its separate inward physical
application and is retained without duplicate extraction.
