# Provider deadline includes initial process identity

An already spawned provider must not block deadline observation while its initial Windows identity is queried. Install output, exit and error observers and the captured command deadline before starting that asynchronous query. Start this single query only while the original command allowance C is positive. Its native timeout is capped at five seconds and the original captured completion remainder K; no deadline is renewed.

This query has a narrow cleanup-only exception to the general rule that identity observation consumes C. After C expires, accept its result only while K remains positive, the exact spawned ChildProcess still has null exitCode and signalCode, and no close has been saved. Node sets those fields before closing the Windows process handle, so this condition retains the original child identity rather than admitting a reused PID. For late capture, an observed exit, saved close, query error, missing identity or exhausted K remains unconfirmed and grants no signal authority. A late identity may authorize only the existing PID/birth/command-hash qualified, descendant-first cleanup within K; it cannot resume stdin, admit late output or turn an expired command into success.

Command expiry preserves the first failure and excludes output delivered after expiry, including while qualified cleanup is pending. Keep initial identity publication and close settlement ordered: a close or timeout while identity is unresolved must not invent identity, drop publication responsibility or report successful process-tree cleanup. Continue to require the captured identity for native tree termination. Do not kill the root early merely to satisfy timing assertions, since that can orphan descendants.

The existing bounded completion grace still governs cleanup. A command deadline is not a promise that every native descendant disappears at that exact millisecond. Verify a live child's query completing between C and K, expiry while initial identity is gated, exit before close, delayed close and missing or changed identity, retained primary errors, discarded late output, and qualified owned process settlement on Windows as well as portable fixtures.
